# Habit Game

Трекер привычек с геймификацией

## Стек

**Бэкенд:** Python + Django  
**Фронтенд:** HTML, CSS, JS  
**БД:** SQLite  
**График:** Chart.js 

## Что сделано

- Регистрация и вход
- Привычки
- Опыт, уровни, золото
- Ежедневные задания
- Магазин скинов
- График активности

## Запуск

```bash
**cmd**
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Далее открыть index.html
